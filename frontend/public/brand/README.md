# Assets institucionales

Los archivos `red-clubes-logo.png` y `red-clubes-mark.png` son los assets actualmente provistos por el proyecto.

Cuando la Municipalidad de Ensenada entregue los originales oficiales, incorporar sin redibujar:

- `municipalidad-ensenada.svg`
- `escudo-ensenada.png`
- variantes SVG oficiales de Red Clubes, si estuvieran disponibles

El frontend no incluye escudos ni firmas municipales recreadas o generadas.
