# Red Clubes

Sistema web para la administración de clubes de abuelos, centros de jubilados y clubes barriales.

## Objetivo

Red Clubes busca facilitar la gestión diaria de un club, permitiendo administrar socios, actividades, cuotas, asistencias, eventos y reportes desde una plataforma simple y ordenada.

## Tecnologías previstas

- Angular
- Java con Spring Boot
- MySQL
- Git y GitHub

## Módulos iniciales del MVP

- Gestión de socios
- Gestión de actividades
- Inscripción de socios a actividades
- Gestión de cuotas
- Dashboard principal
- Reportes básicos

## Estado del proyecto

Proyecto en etapa inicial de análisis y configuración.
